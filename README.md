# VisaEase India 🇮🇳

### Simplifying the Indian Visa Application Journey

VisaEase is a modern, user-friendly visa assistance platform designed to help international travellers understand and navigate the Indian visa application process with ease.

Our goal is to simplify complex visa procedures through an intuitive interface, smart guidance, document assistance and application tracking.

**VisaEase – Your journey to India starts here.**

---

## ✨ Features

### 1. Smart Visa Finder
- Select nationality and purpose of travel.
- Enter intended duration of stay.
- Get suggested visa categories based on sample eligibility rules.
- Understand different visa options.

### 2. Document Checker
- Upload sample passport and photograph files.
- Check file format and size.
- Perform basic image quality checks.
- Identify missing or invalid documents.

### 3. Guided Application
- Step-by-step demo application form.
- Simple and intuitive form navigation.
- Input validation and helpful error messages.
- Application review before completion.

### 4. Application Tracker
- Track sample application progress.
- View application status through a visual timeline.
- Understand different processing stages.

### 5. AI Visa Assistant
- Interactive chatbot for common visa-related queries.
- Simplified explanations of visa requirements.
- Guidance on application procedures.
- Frequently Asked Questions (FAQs).

## 🚀 Getting Started

Follow these steps to run VisaEase locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/HimankMaheshwari/WebVision-Offscript.git
```

**2. Navigate to the project directory**

```bash
cd WebVision-Offscript
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Visit the URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## ⚠️ Disclaimer

VisaEase is an independent hackathon prototype developed for demonstration and educational purposes.

- It is not an official Government of India website.
- It does not process or submit actual visa applications.
- It does not approve or guarantee visa eligibility.
- All application statuses, eligibility suggestions and sample data are for demonstration purposes only.

For official visa applications and updated requirements, visit the [Indian Visa Online Portal](https://indianvisaonline.gov.in/).
